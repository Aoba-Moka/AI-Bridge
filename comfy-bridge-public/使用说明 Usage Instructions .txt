0.Prerequisite: The models required for ComfyUI image generation have already been installed.

1.Configure DiceFrame. In the model interface, add a provider. Configure DeepSeek first, then configure ComfyUI. For the latter, the name and API Key can be anything. For the API, choose OpenAI-compatible. Base URL: http://127.0.0.1:8192/v1 (this is the default). Select the anima model. Type: Image. Assign to: Image Generation Model. Don't forget to click Save.

2.Run ComfyUI; just leave it running in the background.

3.Double-click start-bridge.bat to run it.

4.You can test it in DiceFrame by generating an avatar. If it is blank or garbled, it may have been lost in translation; try changing it to English and testing again.

5.For more details, see the README.
